


### **Remotely** - a Minecraft Mod That Can:
> Ready?
- 📟  Create **Any Minecraft Server** In 5 Seconds.
> Paper, Vanilla, Fabric, And More Are Supported. Install **Modpacks** Servers For Your Friends With 1 Click. You Can **Import** Existing Servers Too.
- ⌨️   Full **Multi-Terminal** Control In-Game.
> You Can Control Minecraft Server, or Your Computer. It's Just a Full And **Fast** Terminal.
- 🗃️  Full **File Explorer** Somehow.
> Supports Many File Types, If a File Isn't Supported, It Will Open The File In it's Default App. You Can `copy / paste / delete` And Drag n' Drop.
- 📝  Full File Editor. It's also AI Powered.
> You Can Also Quicky Open Files In The Default Editor Externally. AI Features Needs An API Key.
- 🪩  Full **Internet Browser** That Also Support Videos And Games.
> You Can Watch YouTube, Twitch, Play Games, Play Minecraft Classic, Doom, Etc...
- 💾   **Resource Browser** install `Plugins / Mods / Modpacks`
> Supports: **Modrinth**`Plugins, Mods, Modpacks`, **Spigot**, **Hangar**. Curseforge Is Planned.
- 📡  Remote Development Support Using `ssh` For All Previous Features.
> This Includes Controlling Your Remote Minecraft Server (You Needs ssh).
- 🖥️ OS That Offers A **Desktop-Like** Experience.
> You Will See One Of The Best Custom UI Mods That Offers Modern User Experience With Full Customizabilty, Including Themes And Shortcuts Customizabilty.
- 🔐 **Secure & Client Side**
> Remotely Only Uses `SSH`, Which Is The World Standard To Connect With Servers. It's a Only Client Side.


> This Project Took a Lot of Time And Effort, Sharing The Project And Giving Feedback Is Appreciated :D
